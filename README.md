# Моя аптечка

Семейное мобильное PWA на React, TypeScript, Vite и Supabase. Общая домашняя аптечка доступна профилям **Мама**, **Папа** и **Сын**. Каждый профиль создаёт свой 4-значный код и вводит его на экранной цифровой панели. Разговоры с помощником и личная история разделены по профилям.

## Как запустить

В PowerShell откройте папку проекта:

```powershell
cd C:\Users\Антон\Desktop\pharmacyapp
npm ci
npm run dev
```

Откройте адрес Vite, обычно <http://localhost:5173>. Выберите профиль и придумайте код, затем повторите его. При следующих входах используйте тот же код. Вкладка «Аптечка» уже содержит 95 позиций из Excel. Срок годности показан только там, где он известен. Сохранены «Зелёный ящик» и «Нижний ящик». Для большинства записей есть локальное фото товара из каталога; конкретная упаковка дома может отличаться, поэтому можно прикрепить своё фото.

Для разработки нужны публичные `VITE_SUPABASE_URL` и `VITE_SUPABASE_PUBLISHABLE_KEY` в `.env`. В текущей рабочей копии они уже заполнены. Секрет OpenRouter помещён в зашифрованный Supabase Vault; браузер получает ответы только через Edge Function. Содержимое `.env` не публикуется и исключено из Git.

## Что проверить в приложении

1. Выберите «Мама», придумайте и подтвердите код из четырёх цифр. Проверьте, что открылась общая аптечка.
   На главной нажмите одну из карточек «Что беспокоит?»: откроется личный чат, который сначала рассмотрит подходящие позиции домашней аптечки и задаст уточняющие вопросы.
2. Откройте вкладку «Аптечка»: должны быть все 95 записей, поиск и фильтры по двум ящикам. Шапка остаётся видимой при прокрутке; неизвестный срок годности не показывается.
3. Откройте лекарство: можно посмотреть упаковки, запросить справку с источником, прикрепить собственное фото, изменить запись, отметить использование и открыть маленький чат об этом лекарстве.
4. Откройте вкладку «Советы»: поговорите с помощником. Шапка остаётся видимой при прокрутке. Если помощник рекомендует покупку конкретного препарата, название и кнопка под ответом откроют поиск покупки. После выхода и входа под другим профилем история первого профиля не должна показываться.
5. Добавьте лекарство через большую кнопку «Добавить»: достаточно названия и срока. Можно приложить фото и попробовать распознать упаковку; распознанные данные нужно сверить вручную.
6. Во вкладке «Купить» введите, например, «Фурацилин». Выберите нужную упаковку: приложение покажет доступные пункты в Кузнечиках, их адреса и цены. Кнопка «На карте» покажет адрес, а «К товару и заказу» откроет точную карточку товара на сайте аптеки. Добавьте товар в корзину и подтвердите выбранный пункт выдачи на сайте.

## Защита данных

PIN хранится в базе как bcrypt-хеш. После пяти ошибок профиль блокируется на 15 минут. Вход оформляется через внутреннюю Supabase Auth-сессию; email и регистрация пользователю не показываются. RLS даёт всем трём профилям доступ к одной аптечке, а `chat_messages` разрешает читать только владельцу соответствующей сессии. Браузеру не выдаются PIN-хеши, ключ OpenRouter или `service_role`.

Первый PIN для каждого ещё не настроенного профиля может создать тот, кто первым выберет этот профиль. Перед публикацией ссылки настройте коды всех трёх профилей на своём устройстве. Четырёхзначный PIN подходит для семейного удобства; не используйте приложение как хранилище особо чувствительных медицинских документов.

## Источники лекарств и аптек

Краткая справка о лекарстве запрашивается по нажатию «Найти сведения» через OpenRouter с веб-поиском. Справка сохраняется только при наличии ссылки на разрешённый источник. Если найденная карточка ЕАПТЕКИ точно совпадает с названием и дозировкой, её публичное фото упаковки показывается в карточке. Для неподтверждённых совпадений используется нарисованная иконка препарата. Точное фото своей упаковки можно добавить камерой.

Цены зависят от конкретной упаковки, наличия и выбранного пункта выдачи. Для каталога ASNA приложение считывает варианты товара и цены Подольска из публичной карточки. После выбора упаковки оно запрашивает список аптек Кузнечиков для этой карточки и сортирует его по цене; данные обновляются при следующем запросе через пять минут. Ссылка ведёт на конкретный товар. Приложение попробует скопировать адрес выбранной аптеки, чтобы его было легче найти при оформлении. ASNA требует выбора пункта выдачи в своей корзине: проверенного публичного перехода, который сразу добавляет товар и фиксирует аптеку, нет. Наличие и итоговую цену подтвердите на сайте перед заказом.

Помощник даёт справочные советы, объясняет возможные причины жалоб и может предложить обсудить безрецептурный препарат с врачом или фармацевтом. Он не ставит окончательный диагноз и не назначает индивидуальные дозировки. При опасных симптомах показывает совет обратиться за неотложной помощью.

## Проверки и структура

```powershell
npm run typecheck
npm run lint
npm test
npm run build
```

`src/FamilyApp.tsx` — новый семейный интерфейс; `src/family.css` — мобильные стили и анимации. `supabase/migrations/` содержит таблицы, RLS, PIN и Vault-доступ. `supabase/functions/family-auth/` отвечает за PIN и внутреннюю сессию, `supabase/functions/family-assistant/` — за личный чат, справки, фото-распознавание и поиск предложений. `scripts/excel_to_json.py` преобразует исходный Excel в `src/data/inventory.json`; импорт в общую базу уже выполнен, повторный запуск не создаёт дубли.

PWA устанавливается через меню Chrome на Android или «Поделиться → На экран Домой» в Safari на iPhone. Для установки на телефон нужен HTTPS-адрес приложения. Уведомления о сроках появляются при открытии приложения после разрешения; фоновая отправка push не настроена.
